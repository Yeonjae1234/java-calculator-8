# java-calculator-precourse

> 2025 우아한 테크코스 - 프리코스 1주차 <문자열 덧셈 계산기>
>

# 기능 요구 사항

- 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

# 프로그램 동작 흐름

1. 문자열을 입력 받는다.
2. 입력 받은 문자열에 ‘커스텀 구분자’를 지정하는 부분이 있는지 확인한다.
3. ‘커스텀 구분자’가 있는 경우 구분자들로 사용할 문자열을 모아둔 ‘구분자 목록’에 추가한다.
    1. ‘구분자 목록’에는 기본 구분자인 `‘,’`, `‘;’` 이 기본적으로 들어있다.
4. String의 split 메소드를 사용하여 구분자로 나누기 위해 매개변수인 regex에 들어갈 구분자 문자열을 생성한다.
    1. 이 때 ‘구분자 목록’에 저장되어 있는 문자열들이 정규식 표현에 해당한다면 `“\\”` 를 붙여 의미 해독을 방지하는 작업이 필요하다.
5. split을 활용하여 문자열을 나눈다.
6. 자른 문자열들을 숫자로 변환하고 더하여 최종 결과를 계산한다.
    1. 이 때 숫자로 변환할 수 없다면 입력 오류로 판단. `IllegalArgumentException`을 발생시킨다.

# 기능 목록

### 1. 커스텀 구분자가 있는지 확인 - `public boolean hasCustomDelimiter()`

- 문자열이 `“//”`로 시작하고, `“\n”`이 있는지 확인한다.
- 있다면 `return true`
- 없다면 `return false`

### 2. 커스텀 구분자 찾고 추가하기 - `public void findCustomDelimiter()`

- `hasCustomDelimiter()`로 커스텀 구분자가 있다면
  - `“\n”`의 위치 찾고 해당 부분 슬라이스한다.
  - 찾은 커스텀 구분자를 ‘구분자 목록’에 추가한다.
- 이 과정은 커스텀 구분자가 여러 개 존재할 수 있다고 가정하고 커스텀 구분자를 모두 잘라낼 때까지 반복한다.

### 3. 구분자 목록을 split 메서드의 매개변수로 사용할 문자열로 만들기 - `public String makeDelimiterString()`

- 저장된 구분자를 하나씩 확인하면서 해당 구분자가 정규식 표현에 해당하는지 확인한다.
    - 정규식 확인 메서드의 결과가 참이라면
        - `“\\”`를 먼저 더한다.
    - 해당 구분자와 `“|”`를 더한다.
- 맨 마지막에 있는 `“|”`는 삭제한다.

### 4. 문자열이 정규식 표현에 해당하는지 확인 - `public boolean isRegexPattern(String delimiter)`

- (split 메서드의 구현 코드 참조)
  - 입력된 문자열이 `.$|()[{^?*+\\` 중에 해당하지 않는다면
  - 문자열의 길이가 2고 앞의 문자가 “\\”, 뒤의 문자가 숫자 또는 알파벳이 아니라면
- split 메서드의 구현 코드는 정규식이 아닌 경우를 찾는 조건이므로 이 결과에 반전을 시켜 return

### 5. 구분자로 문자열을 자르기 - `public String[] splitUserInput()`

- split 메서드의 매개변수로 위에서 만든 구분자 문자열을 넣어 문자열을 자른다.

### 6. 잘린 문자열을 숫자로 변환하고 더하여 최종 값 구하기 - `public int addString(String[] splitString)`

- `Integer.parseInt`를 이용하여 문자열을 정수로 변환한다.
- i) 비어있는 문자열인 경우 숫자가 없는 것으로 봐야하기 때문에 `continue`로 먼저 건너 뛴다.
- ii) 입력 조건이 양수이기 때문에 변환 결과가 0보다 작거나 같다면 IllegalArgumentException을 발생시킨다.
- iii) 변환할 수 없어 Exception이 발생하면 IllegalArgumentException을 발생시킨다.
