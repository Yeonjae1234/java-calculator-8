> 2025 우아한 테크코스 - 프리코스 1주차 <문자열 덧셈 계산기>
>

# 기능 요구 사항

- 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

# 프로그램 동작 흐름

1. 문자열을 입력 받는다.
2. 입력 받은 문자열에 ‘커스텀 구분자’를 지정하는 부분이 있는지 확인한다.
3. ‘커스텀 구분자’가 있는 경우 구분자들로 사용할 문자열을 모아둔 ‘구분자 목록’에 추가한다.
    1. ‘구분자 목록’에는 기본 구분자인 `‘,’`, `‘;’` 이 기본적으로 들어있다.
4. String의 split 메소드를 사용하여 구분자로 나누기 위해 매개변수인 regex에 들어갈 구분자 문자열을 생성한다.
    1. 이 때 ‘구분자 목록’에 저장되어 있는 문자열들이 정규식 표현에 해당한다면 `“\\”` 를 붙여 의미 해독을 방지하는 작업이 필요하다.
5. split을 활용하여 문자열을 나눈다.
6. 자른 문자열들을 숫자로 변환하고 더하여 최종 결과를 계산한다.
    1. 이 때 숫자로 변환할 수 없다면 입력 오류로 판단. `IllegalArgumentException`을 발생시킨다.

# 기능 목록

### 1. 커스텀 구분자가 있는지 확인

- 문자열의 앞에 `“//”`가 있고, `“\n”`이 있는지 확인한다.
    - `“\n”`의 위치 찾고 해당 부분 슬라이스한다.
    - 찾은 커스텀 구분자를 ‘구분자 목록’에 추가한다.

### 2. 구분자 목록을 split 메서드의 매개변수로 사용할 문자열로 만들기

- 저장된 구분자를 하나씩 확인하면서 해당 구분자가 정규식 표현에 해당하는지 확인한다.
    - 정규식 확인 메서드의 결과가 참이라면
        - `“\\”`를 먼저 더한다.
    - 해당 구분자와 `“|”`를 더한다.
- 맨 마지막에 있는 `“|”`는 삭제한다.

### 3. 문자열이 정규식 표현에 해당하는지 확인

- (split 메서드의 구현 코드 참조)
- 입력된 문자열이 `.$|()[{^?*+\\` 중에 해당한다면 `return true`
- 문자열의 길이가 2고 앞의 문자가 “\\”, 뒤의 문자가 숫자 또는 알파벳이라면 `return true`
- 그 외의 경우는 `return false`
